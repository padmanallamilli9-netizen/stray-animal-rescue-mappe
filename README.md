Stray Animal Rescue Mapper 🐾

Project Description

Stray Animal Rescue Mapper is a web-based application designed to help people quickly report injured, sick, or stranded animals. Users can submit details such as animal type, problem description, location, and contact information. The reported cases are displayed on a dashboard, allowing rescue volunteers and organizations to identify animals in need and respond efficiently.

The application also provides a map-based view of reported locations, making it easier for rescue teams to locate animals and coordinate rescue operations. This project aims to improve community participation in animal welfare and reduce response time for animal rescue efforts.

Features

- Report injured or stray animals
- Submit location and contact details
- Interactive rescue dashboard
- Map-based animal location tracking
- Emergency case monitoring
- User-friendly interface

Technologies Used

- HTML
- CSS
- JavaScript
- Vite

Future Enhancements

- Real-time rescue team notifications
- User authentication and login
- Image upload for animal reports
- Rescue status tracking
- Mobile application support
